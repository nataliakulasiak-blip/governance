# Fotografie del sito

Salvare qui le immagini con questi nomi esatti. Il formato indicato è quello con cui la foto viene ritagliata: una foto più grande va benissimo, viene adattata da sola.

## Consigli

- Formato `.jpg` per le fotografie, qualità 80: pesano poco e si vedono bene.
- Sotto i 500 KB per foto, altrimenti il sito si apre lento sul telefono.
- I nomi vanno scritti tutti in minuscolo, senza spazi e senza accenti.
